# DivaMania6K Live View v1.0

Windows x64 原生六轨视图插件，使用 DivaModLoader 的 D3D11 回调。

## 使用

安装在游戏 mods/DivaMania6K 下，config.toml 引用 DivaMania6K-1.0.dll。正常退出并重新启动游戏后生效，不支持热加载。

- 菜单默认隐藏，进入歌曲显示 6K LIVE，暂停显示 PAUSED。
- 六轨顺序：S 左滑 / D ←（□） / F ↑（△） / J ↓（×） / K →（○） / L 右滑。
- 每轨同时显示方向图标与键帽；下落音符使用对应图标和颜色。S / D / F / J / K / L 及方向键支持按键亮起，两侧 Ctrl 也可触发滑条轨道的显示反馈。本插件不修改原游戏键位绑定。
- F8 显示或隐藏；F9 重新读取 Player.ini（已不再暂停测试动画）。
- 音符来自游戏解析的完整谱面，直接使用游戏判定时钟。无模拟音符或墙钟计时。
- 普通音符、同时押固定分轨；HOLD 标记 H，不虚构释放尾部。
- 连续滑条合并为真实时间区间；同方向重复滑条显示 2 标记。
- 保留原游戏谱面显示。仅改变视图，不注入按键、不改判定、不自动将同向双滑条转成单键。

## 设置

Player.ini / [View]：
- FallTimeMs=1200，下落窗口 200–5000ms。
- OffsetMs=0，显示偏移 -1000–1000ms，正数使音符更晚到达判定线。
- HideInMenus=1，无活动歌曲时隐藏；改为 0 显示空轨道等待界面。

修改后按 F9 应用。偏移只影响显示。

## 数据适配与优化

只读 ReadProcessMemory 读取本进程数据，不安装游戏代码 Hook。模块基址加 RVA，核对两个 getter 的指令和目标地址；不匹配则停用读谱。当前结构已通过本机 build 11004484 的 IDA 数据库和运行中的暂停状态交叉确认；其他版本未验证。

- GetPVGameData RVA 0x266720，静态对象 RVA 0x12C2330。
- GetPVGameArcade RVA 0x27DDA0，静态对象 RVA 0x12F0F50。
- PV+181680 为音符组 vector，组大小176，组内+160为int64纳秒判定时间。
- arcade+78480 为游戏判定时钟（float秒）；PV+0/+1 为 loaded/paused。

每帧读取时钟和状态；整谱每秒核对一次，切歌及重新进入时刷新。排序及前缀结束时间索引缩小每帧可见范围。非法地址或长度停止显示；未知类型跳过并记录。游戏暂停、重开、回退直接跟随游戏时钟。

使用 D3D11.1 状态切换隔离并恢复图形管线，兼容单线程设备，每帧释放 backbuffer 引用。

## 测试与限制

test.cmd 测试键型映射、同时押、连续滑条区间、双滑标记、未知类型、暂停、重开/回退、卸载清理与非法指针。普通及 SINGLETHREADED WARP 设备测试绘制、状态恢复与缓冲区缩放。

如 build/real-chart.bin 存在，还会测试实际采集谱面；当前样本236组转换成204个显示对象，未知类型0。测试 DLL 单独命名为 DivaMania6K-test.dll；发行 DLL 不包含测试入口。

仍需实机核对不同歌曲/难度、连续与双滑条及视觉偏移；自动测试不代表所有官谱已验证。HOLD 有入场提示条和基于实际奖励状态的实时长条，不修改奖励规则。

DivaMania6K.log 记录兼容检查、谱面加载、D3D初始化及首帧提交。旧版报错保留在历史中，请看末尾。退出游戏后将 config.toml 的 enabled 改为 false 即可停用。

## 构建

Visual Studio C++ x64 与 Windows SDK；运行 build.cmd，输出 build/DivaMania6K.dll，安装时复制为版本化名称。静态链接 C++ 运行库；需要 D3D11.1 与 d3dcompiler_47。

## 连击与判定提示（0.2.6）

六轨内部居中显示游戏实际 COMBO；断连时立即显示 0。判定为 COOL / FINE / SAFE / SAD / WORST / WRONG，使用游戏判定计数的变化，不根据键盘输入猜测。WRONG 使用总计数与正确按键计数的差值识别。同一渲染帧内出现多种判定时合并显示，例如 COOL/FINE，避免猜测它们的先后顺序。

判定使用实际经过时间计时，默认显示500毫秒，最后150毫秒淡出；连击常驻。暂停时清除判定文字，继续后不重放旧提示。重开、时间回退、退出歌曲时清除旧提示并重置计数基线。没有新增输入或判定修改。

新增验证覆盖：正确判定、按错键、漏键、同帧多判定、提示到期、回退清理和非法统计数据。
Player.ini 的 [View] 新增 JudgementDurationMs=500，可设为100至2000毫秒，修改后按F9应用。连击和判定为轨道内居中的透明文字，无侧边面板。

FeedbackPositionPercent=45 控制反馈在轨道内的纵向位置，按轨道顶部至判定线的百分比计算，数值越小越靠上，范围10–85。连击数字默认位于45%附近，判定在其上方。修改Player.ini后按F9应用。

## 窗口位置与点击光效（0.2.6）

PositionY=-60：整个六轨区域按1080p参考尺寸上移60像素，随分辨率缩放。负数上移、正数下移，范围-70至150。连击与判定一起随轨道移动。

ClickEffects=1：亮蓝色点击光柱、白色判定线闪光及扩散粒子。按住时保持较弱蓝光，松开后衰减。设为0关闭。输入仅在游戏窗口前台且歌曲未暂停时响应，失去焦点或暂停时清除光效。

光效由配置展示的S/D/F/J/K/L及对应方向键、两侧Ctrl的按键触发，是输入视觉反馈，不代表游戏判定成功。本版不改变输入和判定逻辑。

修改上述Player.ini参数后按F9生效。测试夹具模拟双键点击并验证两种设备及窗口尺寸下的绘制；发行DLL不包含测试按键入口。
## 多押橙框与短光柱（0.2.6）

二押、三押、四押及双滑条按原谱面音符组识别，参与同组同时押的音符头显示橙色边框。保留方向图标、HOLD和双滑条标记。连续滑条仅在起始音符属于多押组时为其头部显示橙框，不把后续重叠误当作起始多押。

MultiPressOutline=1 启用多押橙框，设为0关闭。
ClickBeamHeight=90 为1080p参考尺寸下的点击光柱最大高度，比旧版180减半；范围20至240。较小的值更短，判定线闪光与粒子保留。修改配置后按F9应用。
## HOLD 长条优化（0.2.6）

H音符入场时显示同轨道颜色的渐隐提示条，顶部没有释放端点；它只提示按住操作，不把图形长度当作固定松键时刻。

命中后，直接读取游戏实际HOLD管理器（arcade+78752）：state在+12，按键掩码在+16，累积计时在+24，最后追加HOLD时刻在+48。根据原函数0x140273120验证的5秒奖励窗口计算剩余时间。实际持续中的长条固定在判定线，随剩余时间缩短；新增HOLD可延长共享奖励窗口，松开或进入MAX状态清除长条。显示不依赖键盘轮询判断HOLD成功。

HOLD使用真实游戏状态，尚需在更多含HOLD的曲目中核对效果。预览图是独立D3D测试夹具，包含模拟的正在持续HOLD与未来H音符，不代表实机截图。

## 轨道分隔线（0.2.7）

六轨间使用柔和的冷白细线，共享边界只绘制一次，补齐左右外框。分隔线对齐实际屏幕像素，在较小窗口下至少保持1像素，避免粗细不一或消失；延伸到键帽区域下缘，不穿过底部快捷键文字。音符、长条和点击光效显示在分隔线上方。

Player.ini / [View]：LaneLineOpacity=30 控制不透明度（0–100，0隐藏），LaneLineWidth=1 控制1080p参考宽度（1–3，随分辨率缩放）。外框亮度略高于内部细线。安装新版DLL需重启游戏，之后修改这些参数按F9应用。

## 点击光柱淡出（0.2.8）

点击光柱及判定线闪光的淡出窗口从按下起260毫秒延长至360毫秒，按住期间继续保持弱蓝光；光柱最大长度、峰值亮度及粒子速度保持原设置。Player.ini / [View] 的 ClickFadeMs=360 可调节淡出窗口，范围100–1000毫秒，修改后按F9应用。暂停或失去焦点仍立即清除光效。

## 宽度与背景透明度（0.2.9）

六轨每轨从72加宽至90参考像素，总轨道宽度从432变为540，保持水平居中，随窗口分辨率缩放。音符、HOLD、分隔线、键位与点击光效同步适配宽度。

Player.ini / [View] 的 LaneWidth=90 设置单轨1080p参考宽度，范围48–140。BackgroundOpacity 设置背景不透明度，范围0–100，0完全透明，100完全不透明。背景仅绘制一层。安装新版DLL需重启游戏，之后修改参数按F9应用。

## 背景和彩色填充（0.2.10）

BackgroundOpacity=95：深色背景为5%透明。ColoredOpacity=100：彩色音符、HOLD提示条、持续HOLD、滑条长条和底部键位填充为0%透明，即完全不透明；可设置0–100的不透明度。方向图标及橙框保持清晰，点击光柱、粒子与判定文字仍按原时长淡出。轨道宽度保留90。配置修改后按F9应用；升级DLL需完整退出并重启游戏。

## 纯色箭头与图标底色（0.2.11）

下落音符改为完全不透明的单色箭头，去除矩形底板、底线和黑色描边，保留六轨对应颜色、H和双滑条标记。多押仍显示橙框，框内不再叠加橙色填充；长条与下落箭头之间留出空间，避免同色融合。

ArrowBackgroundOpacity=20 设置底部箭头区域的彩色背景不透明度（0–100），默认80%透明，箭头本身仍完全不透明。深色总背景维持5%透明，长条保留 ColoredOpacity 设置，点击光效维持360毫秒淡出。底部键帽与边缘提示保持清晰。首次升级需重启游戏，之后修改配置按F9应用。

## HOLD尾部可视提示（0.2.17）

HOLD尾部使用加粗白框、深色内部和END文字，与普通音符头明确区分。尾帽在全部音符之后绘制，避免结束时刻的同轨新音符盖住尾部。长条超过当前下落窗口时，在轨道顶部方向图标下显示剩余秒数（例如5.9S）；尾部进入屏幕后，替换为跟随真实预计算位置下落的尾帽，抵达判定线后按原计划清除。尾点不因按键重新拉长，不改变5秒MAX或六键推荐路线计算。暂停时倒计时冻结，结束或松键时随长条清除。

WARP测试额外核对尾帽与后续同轨音符重叠时仍保持可见。新版DLL需完整退出并重启游戏后生效。

## HOLD提前计算长度（0.2.16）

加载谱面时预计算HOLD推荐持续区间：单次HOLD在5秒MAX结束；在MAX之前追加不同键的HOLD，所有持续中的HOLD共享延长后的尾点。依据IDA的0x140272FC0（追加不同键时重置lastAdded）和0x140273120（timer-lastAdded达到5秒进入MAX）。当前一轨一键映射需要释放后重击同一逻辑键，因此后续普通/HOLD音符与持续键冲突时结束当前共享区间；歌曲结束时间也会截断区间。同一时刻的音符批量处理，避免顺序导致错误延长。

完整长条和尾端从入场开始按预计算区间绘制，命中后头部固定在判定线，尾部沿同一时间轴继续下落，不再切换成实时5秒条而突然变长。超出屏幕顶部的部分正常裁剪。HOLD仍根据游戏实际持续键状态清除，提前松键、MAX或漏键不会维持虚假长条；重开和切谱重新计算。自动测试包含追加、四键、重击、MAX、歌曲结束和命中前后尾点不变。

原作HOLD不提供固定释放尾点；这里是按连续正确命中、当前六键映射推导的推荐路线，不是官方谱面释放判定。双绑/宏换手、主动提前放弃HOLD、追加HOLD漏键或实际判定偏移会改变真实奖励结束时刻。本版不改原游戏HOLD规则，显示尾部不在点击时重新拉长。不同曲目的实机表现仍需核对。

## 下落动画平滑（0.2.15）

SmoothAnimation=1：使用高精度QueryPerformanceCounter，在游戏时钟采样之间平滑更新下落位置，减少高刷新率下重复时间样本造成的停顿。只在观察到游戏时钟前进后启用补间，显示最多领先一个已观察到的时钟步长（上限33.3毫秒），源时钟停滞时也不会持续漂移。暂停、歌曲结束、重开、跳转、切谱及长时间卡顿立即重新同步。普通音符、HOLD和连续滑条使用同一显示时间；歌曲计时、进度和真实判定仍使用原始游戏时间。

实际绘制频率跟随游戏OnFrame回调，没有新增限帧、解锁帧率或修改游戏速度。该功能改善位置平滑度，不保证提升实际FPS。设SmoothAnimation=0并按F9可关闭。自动测试模拟60Hz游戏时钟配合60/120/144/240 FPS渲染，检查帧间移动、单调性、领先上限、暂停、结束、重开及卡顿恢复。

## 歌曲进度与结束计时（0.2.14）

六轨背景上方、时间文字下方显示细条歌曲进度，时间格式为当前分:秒 / 总分:秒。总时长只读游戏 PV+0x2D330 的int64纳秒值（解析器0x140245C50写入，结束时间字段），不使用最后一个音符估算。读取不到有效时长时显示 --:--，进度条为空。

计时跟随游戏时钟，暂停时保持；到达总时长后钳制并停止。PV+0x2D17D结束标记触发时锁定最后游戏时间，提前失败保留实际已玩时长；结果画面时钟继续增长也不会推动计时。结束后显示6K ENDED、进度条变绿，并清除音符和点击效果。重开、回退、换谱及卸载重置结束状态。自动验证覆盖正常完成、提前结束、结果停留、暂停恢复、重开、时长缺失及两种D3D设备和窗口尺寸；真实曲目结果画面仍需核对。

## 判定后清除音符（0.2.13）

每帧只读 arcade+40 的64个实时音符槽（每项1224字节），按+72的纳秒时间、+1216的谱面组索引、+20的键型匹配显示音符。+1140为判定，21表示未判定，0–20表示游戏已经处理；命中、按错或漏键一旦被游戏判定，普通音符及HOLD入场音符立即从视图中清除，不根据按键轮询猜测命中。早按、空按不会移除未判定音符。

HOLD命中后入场提示清除，实际持续条仍跟随HOLD管理器；连续滑条保留至真实结束时间，避免清除起点时截断后续长条。音符槽复用不使已清除音符复现；重开、时间回退、重载谱面及离开歌曲会清空记录。无法读取实时槽时保留原来的按时钟显示方式。本版已通过构造内存测试及绘制测试；尚需在游戏内核对不同曲目的清除效果。

## 纯色下落音符（0.2.12）

下落音符使用完全不透明的纯色横条，取消音符头中的箭头。每轨沿用对应颜色，多押橙框、H和双滑条标记、HOLD及连续滑条长条保留。轨道顶部与底部的方向图标继续用于键位指引，深色背景和底部图标区域透明度维持当前配置。新版DLL需完整退出并重启游戏后生效。
